# Órák és jelenlét

A kurzusok órái külön `course_sessions` rekordokként vannak tárolva. A jelenlét mindig egy konkrét órához és egy konkrét `course_enrollments` beiratkozáshoz tartozik.

Admin nézet:
- heti naptár;
- új óra felvétele;
- óra megtartottra vagy elmaradtra állítása;
- teljes névsor jelenlétének rögzítése;
- gyors „Mindenki jelen” művelet.

Diákportál:
- heti órarend;
- saját jelenléti állapot;
- korábbi és következő hetek lapozása;
- heti jelenléti összesítés.
